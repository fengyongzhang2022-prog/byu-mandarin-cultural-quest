# 第三稿至完整版：迭代说明

本说明记录产品从课堂原型发展为可完整演示、可保留研究记录的 GAI 沉浸式文化任务的主要调整。当前的完整验收标准见 [06_完整版产品验收清单.md](06_完整版产品验收清单.md)。

## 面向美国中高级学习者的差异化支持

学生界面不再使用“低／中／高”或带有能力判断色彩的名称。所有学习者完成同一文化任务，并可自行选择、随时切换下列支持方式：

| 支持方式 | 主要作用 |
|---|---|
| 引导表达 | 提供关键词、句架与较短的追问，帮助学习者启动表达。 |
| 自主协商 | 以交际功能提示推动学习者说明理由、补充例子和调整说法。 |
| 批判探究 | 加入冲突材料与证据审视问题，练习识别概括、限定表达和跨文化调解。 |

切换记录进入研究数据，但三种选择均不改变核心学习目标，也不是给学生贴能力标签。

## 完整体验闭环

`Research Pre → Enter → Discover → Interact → Compare → Explain 1 → GAI Story Studio → Explain 2 → Research Post`

- 前测包括 pre-quiz、游戏熟悉度、无资料文化解释**录音与转写**；建议至少 1 分钟，最长 3 分钟。学生可以回听，也可重新录制覆盖先前版本。
- Discover 使用《黑神话：悟空》场景的游戏化入口，结合场景物证、教师文化说明、多元声音，以及“批判探究”可见的冲突材料。
- Interact 中“西游行者”承担 Story Guide、Virtual Character 与 Language Interaction Partner，不直接替学生讲解，而是追问、回应并推进故事。
- Compare 中国际玩家 Maya 以可能的误解或不恰当类比带出跨文化协商；学生可打开表达工具和证据袋。
- Explain 留下初次中文文化讲述。录完后学生可回看，必要时重新录制并覆盖；GAI随后才给出一条关键反馈和“中国故事卡”。
- 后测、学习日记、访谈线索、互动日志、前测音频及前后解释材料共同进入研究记录。

## 研究端与数据边界

教师端展示支持方式、前后测、材料整合、两个 AI 角色对话、初次与修订讲述、GAI 故事卡、反思和人工编码。前测音频与讲述视频默认只保留在录制所在浏览器，可在同一设备的教师端回听／查看；导出的 JSON 和 CSV 保存文本、时长与完成状态，不自动嵌入媒体文件。

正式研究前仍须依照 BYU 适用流程完成伦理审查、同意书、账号管理和数据保存安排。
