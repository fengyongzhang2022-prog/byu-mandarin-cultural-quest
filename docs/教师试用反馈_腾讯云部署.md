# 教师试用反馈：腾讯云部署说明

## 这套流程收集什么

教师从下列链接进入：

`https://你的域名/forest.html?teacher-review=1`

1. 入口仅确认两项筛选信息：是否曾在美国教授中文、教龄。
2. 在学习体验前展示教学目标、适用对象和教师/GAI 的职责分工。
3. 完成体验时，页面自动弹出 5 个总体评价量表题和 2 个必答开放题。
4. 反馈经 Next.js 服务端转发，写入腾讯云 MySQL 的 `green_teacher_feedback` 表。
5. 使用教师研究账号登录后，可在 `/teacher-feedback.html` 查看匿名汇总、逐份文字反馈及可选的教师语音反馈。

不会保存姓名、邮箱、学习者数据或学习者音视频。教师可选提交一段最长 8 分钟的最终口述反馈；不会上传其在学习任务中产生的练习录音。

## 教学目标来源

页面目标依据 `附件2_GAI支持下的中国治沙故事听说教学 最新版.docx` 的“单元学习目标”整理。学习者完成后应能够：

1. 理解信息：识别主旨、关键时间节点、人物、数字与细节。
2. 分析关系：说明 5000 美元、5 万多棵树与长期治沙行动之间的关系，并调用相关国情背景。
3. 评价信息：发现片面标题的时间、主体或因果问题，并基于事实修改。
4. 完成讲述：面向美国受众完成 60–90 秒、具有时间线与证据的中文表达。
5. 判断 AI 反馈：判断建议是否适合任务与受众，并在再表达中体现自己的取舍。

量表题评价 GAI 的实际教学价值、治沙故事理解、容错性表达环境、讲好中国故事的支持，以及采用意愿。

## 部署变量

### 腾讯云 Node 服务 `server/green-data-api`

在原有变量之外增加：

```text
GREEN_TEACHER_FEEDBACK_ADMIN_KEY=请生成一个至少32位的随机值
TENCENT_COS_SECRET_ID=
TENCENT_COS_SECRET_KEY=
TENCENT_COS_BUCKET=
TENCENT_COS_REGION=
```

该变量仅用于允许项目服务端读取匿名反馈；不能写进浏览器代码。

### 网站的 Vercel / Next.js 项目

新增以下服务器环境变量：

```text
GREEN_DATA_API_URL=https://你的腾讯云数据服务域名
GREEN_PROXY_SECRET=与腾讯云服务相同的 GREEN_PROXY_SECRET
GREEN_TEACHER_FEEDBACK_ADMIN_KEY=与腾讯云服务相同的管理密钥
```

这些变量不可使用 `NEXT_PUBLIC_` 前缀，也不要提交到 Git。

## 首次上线顺序

1. 部署或重启腾讯云 Node 服务。首次提交反馈时会自动创建 `green_teacher_feedback` 数据表。
2. 在 Vercel 设置上述三个网站环境变量后重新部署网站。
3. 用普通试用账号打开教师链接，完成两项筛选并走到问卷；提交一条测试反馈。
4. 用现有教师研究账号登录，访问 `https://你的域名/teacher-feedback.html`，确认能看到 1 条测试反馈。
5. 用教师账号打开汇总页，确认可以播放这条测试录音。
6. 删除测试记录时，同时删除腾讯云 COS 中同一 `id` 的音频对象；生产阶段不要收集姓名、邮箱或学习者资料。

## COS 权限与生命周期

1. 建立一个**私有读写**的 COS 存储桶；建议对象前缀只用于 `teacher-feedback/`。
2. 为服务账号授予该存储桶内 `PutObject`、`GetObject`、`DeleteObject` 权限；密钥只放在腾讯云 Node 服务环境变量中。
3. 在 COS 控制台为 `teacher-feedback/` 配置生命周期：标准存储、上传后 90 天自动过期删除。不要为此小规模音频使用低频或归档存储，避免最短存储期和取回复杂度。
4. 教师反馈页的音频经 Next.js 代理，仅教师研究账号可读取；COS 对象不公开。

## 关于语音开放题

第 6、7 题为必答：教师可分别填写文字，或用一段最长 8 分钟的最终语音依次回答两题。浏览器会以低码率 WebM/Opus 录制；只有点击“提交反馈”后才上传。
