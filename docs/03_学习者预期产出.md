# 学习者预期产出设计

## 产出轨迹

| 阶段 | 学习者产出 | 可观察证据 |
|---|---|---|
| Pre | 无资料口头解释录音（建议至少1分钟，最长3分钟）及文字转写 | 起点材料，用于与讲述1、讲述2比较 |
| Discover | 多类材料整合札记（建议25／40／55字） | “材料A显示……；材料B进一步说明……；材料C提醒我们……”；是否点出材料性质差异 |
| Interact | 点击圆点与金池长老连续对话（2／2／3轮起，可不间断追问） | 是否基于前一回答追问、澄清和确认，而非只问定义；后台保留原始语音、转写与时长 |
| Compare | 点击圆点与黑熊精连续完成口语文化调解 | 是否承认相似、引用场景证据、指出局限并调整表达；后台保留双方交际过程 |
| Explain 1 | 60秒（批判探究方式75秒）视频讲述 | 视频／声音／转写、材料引用、段落结构、限定表达 |
| Feedback | 一条最重要的修改建议 | 反馈焦点（材料证据／类比局限／限定表达／段落连接／结论句）是否被理解 |
| Explain 2 | 20秒（批判探究方式25秒）修订重讲 | **反馈指向的功能是否真的出现在第二版**；语言标记净增 |
| Reflect | 跨文化反思 | “我的看法如何改变？还需要核实什么？” |

## 高级学习者示例（教师参考，不直接展示给学生）

我理解你为什么把古观音禅院看成战斗地图，因为游戏里确实有火焰、敌人和关卡推进。不过，这个类比只能解释一部分。材料A里的三口钟说明钟声不仅是机关，也把天命人带进寺院空间；材料B的金池长老画面把僧人形象与战斗叙事连在一起；与此同时，材料C里的黑熊精与火焰让执念和冲突继续升级。游戏借用了寺院、钟声与山林的文化联想，但不能把这种改编当成现实寺院的完整样子。更准确地说，古观音禅院是游戏中组织探索、人物与冲突的文化化场景。

## 差异化支持（已在产品中实现为可切换方式）

- **引导表达**（Intermediate High–Advanced Low）：提供段落结构、关键词和句架，札记建议25字，每个角色2轮，AI可给选项。
- **自主协商**（Advanced Mid）：只提供功能提示，札记建议40字，每个角色2轮，AI要求给理由或例子。
- **批判探究**（Advanced High）：增加冲突材料D与刻板印象挑战，札记建议55字，每个角色3轮，讲述75秒＋重讲25秒，要求评价证据可靠性。

学习者可随时切换支持方式；切换的时间点与所在阶段被记录，切换频次本身即“支架需求”指标，而不是能力等级判定。

## 研究记录

- 初次产出与修订产出的文本／视频，以及两者的语言标记对照（限定表达、语篇连接、材料证据、类比局限）；
- 反馈内容、焦点与来源（AI／规则回退／学生自选）；
- 支持方式的初始选择与全部切换记录；
- 打开了哪些材料、整合札记、是否使用句架；
- AI追问与学习者追问的类型；
- 学习者每轮原始语音、语音时长、自动转写、AI角色回应文本与角色语音重播记录，供教师分析发音、流利度、追问和协商策略；学生端不要求查看转写或回听。
- 中文水平、游戏熟悉度、既有文化知识；
- 课后反思与访谈。
