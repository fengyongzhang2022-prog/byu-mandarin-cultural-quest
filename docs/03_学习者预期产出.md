# 学习者预期产出设计

## 产出轨迹

| 阶段 | 学习者产出 | 可观察证据 |
|---|---|---|
| Discover | 多材料整合札记 | “材料A显示……；材料B进一步说明……；材料C提醒我们……” |
| Interact | 探究性问题＋追问＋确认 | 问题是否基于前一回答继续推进，而非只问定义 |
| Compare | 文化调解回应 | 是否承认类比价值、引用证据、指出局限、调整给听众 |
| Explain 1 | 60秒视频讲述 | 视频/声音/转写、材料引用、段落结构、限定表达 |
| Feedback | 一条最重要的修改建议 | 学习者能否理解反馈指向的功能 |
| Explain 2 | 20秒修订产出 | 修改是否真正出现在第二版 |
| Reflect | 跨文化反思 | “我的看法如何改变？还需要核实什么？” |

## 高级学习者示例（教师参考，不直接展示给学生）

我理解你为什么把土地庙和教堂作比较，因为它们都是带有仪式意义的空间，也可能让人寻求精神上的安慰。不过，这个类比只能解释一部分。场景里的小神龛和山路位置说明土地庙更强调地方性；上香和供物既可能与信仰有关，也可能是地方习俗或家乡记忆。与此同时，不同人的参与方式并不一样。游戏把土地庙改编成休息和传送点，是利用了“停留与守护”的文化联想，但不能把这种机制当成现实文化的完整样子。更准确地说，土地庙是一种具有地方意义、同时又有多种当代理解的文化空间。

## 分层支架

- Advanced Low：提供段落结构和连接词库，要求至少两类材料。
- Advanced Mid：只提供功能提示，要求追问并根据听众调整表达。
- Advanced High：增加冲突材料或第二个国际听众，要求评价证据可靠性和潜在刻板印象。

## 研究记录

- 初次与修订产出文本/音频；
- 使用了哪些材料、句架和提示；
- AI追问与学习者追问的类型；
- 是否使用文化限定与听众调整；
- 中文水平、游戏熟悉度、既有文化知识；
- 课后反思与访谈。
