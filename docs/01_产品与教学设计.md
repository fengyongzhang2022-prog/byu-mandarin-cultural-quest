# 寻迹：生成式AI支持的中文文化调解任务

## 产品定位

面向美国大学高级中文学习者的 6–8 分钟沉浸式任务。学习者进入原创神话旅行场景，整合文化材料、询问角色、回应国际玩家的类比，最终用中文形成一段面向真实听众的文化解释。

首个任务聚焦土地庙。产品不是《黑神话：悟空》的游戏复刻，也不把游戏设定当作文化事实；游戏化场景仅作为进入文化探究的现代媒介。

## 教学闭环

1. Enter：接受“澄清 Chinese church / save point 类比”的任务。
2. Discover：整合场景物证、教师改写文化说明、教学模拟访谈。
3. Interact：用口语向土地公提出至少两次探究性问题和追问；AI用角色化中文语音回应，学习者可不限次数继续问。
4. Compare：用口语与国际玩家协商类比的价值、局限及可能造成的误解；三条场景证据始终保留在“证据袋”。
5. Explain：打开摄像头和麦克风，完成60秒组织完整的中文视频讲述，同时保留视频、转写与时间戳。

前测在进入场景前完成20–30秒无资料口头解释；后测以60秒文化讲述视频和理解变化自评构成。学生端只显示情境、角色话语、证据与当前行动，ACTFL对齐、研究量规和专家说明全部移到研究端。

## 文化内容边界

- 文化产品：土地庙、神龛、香炉、供物、山路位置。
- 文化实践：上香、供奉、祈求平安、路过观看；实践因地区、家庭、年龄和个人而异。
- 文化视角：地方性、社区守护、家乡记忆、个人信仰与非信仰性文化参与。
- 现代再创造：游戏可把土地庙改编为休息、传送或存档机制，但游戏机制不是现实习俗的完整说明。
- 避免概括：不使用“所有中国人”“中国唯一的神”“土地庙就是教堂”等无边界判断。

## 五位专家共识

- 一次只处理一个文化元素、一个核心误解和一个最终产出。
- AI负责追问、扮演与反馈，不负责临场创造文化事实。
- 教师审核材料与事实边界，并可随时接管。
- 学习者必须留下可观察的语言证据，不以对话轮数代替学习成效。
- 研究比较初次产出与修订产出，同时记录材料使用、提示使用和游戏熟悉度。
