# 部署与域名说明

## 环境变量

生产环境只设置服务端机密变量：

`DEEPSEEK_API_KEY`

禁止把密钥写进 `public/3.html`、浏览器脚本、GitHub仓库或任何以 `NEXT_PUBLIC_` 开头的变量。

## Vercel

1. 项目已部署到 Vercel，生产地址为 `https://byu-mandarin-cultural-quest.vercel.app`。
2. 生产环境已配置 `DEEPSEEK_API_KEY` 与服务端会话签名变量；密钥只在服务端使用。
3. GitHub 仓库为 `https://github.com/fengyongzhang2022-prog/byu-mandarin-cultural-quest`。

## 研究数据

当前原型采用本地优先方式：每台学生设备保存匿名研究记录和视频，学生导出JSON及WebM视频；教师端可批量导入JSON、进行ACTFL文化解释人工编码并导出前后测CSV。正式研究若要求自动集中收集，应先完成伦理审查、访问权限、数据保存期限与删除机制，再接入受控数据库；不要把学生视频写入GitHub仓库。

## 自定义子域名建议

推荐：`quest.usmandarincurriculumlab.com`

该子域名已绑定并通过 Vercel 校验。腾讯云 DNS 记录如下：

- 主机记录：`quest`
- 记录类型：`CNAME`
- 记录值：`2cc6f3b80c41186d.vercel-dns-017.com.`

Vercel 所有权验证记录：

- 主机记录：`_vercel`
- 记录类型：`TXT`
- 记录值：`vc-domain-verify=quest.usmandarincurriculumlab.com,3f02fdf650c907a4a71b`

正式访问地址：`https://quest.usmandarincurriculumlab.com`

DNS 生效并通过 Vercel 校验后，HTTPS 证书由 Vercel 自动配置。
