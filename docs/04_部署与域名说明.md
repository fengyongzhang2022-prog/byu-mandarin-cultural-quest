# 部署与域名说明

## 环境变量

生产环境只设置服务端机密变量：

`DEEPSEEK_API_KEY`

禁止把密钥写进 `public/3.html`、浏览器脚本、GitHub仓库或任何以 `NEXT_PUBLIC_` 开头的变量。

## Vercel

1. 从 GitHub 仓库导入项目。
2. Framework Preset 选择 Next.js。
3. 在 Project Settings → Environment Variables 添加 `DEEPSEEK_API_KEY`，勾选 Production。
4. 部署后先使用 `*.vercel.app` 域名测试。

## 研究数据

当前原型采用本地优先方式：每台学生设备保存匿名研究记录和视频，学生导出JSON及WebM视频；教师端可批量导入JSON、进行ACTFL文化解释人工编码并导出前后测CSV。正式研究若要求自动集中收集，应先完成伦理审查、访问权限、数据保存期限与删除机制，再接入受控数据库；不要把学生视频写入GitHub仓库。

## 自定义子域名建议

推荐：`quest.usmandarincurriculumlab.com`

在 Vercel 添加该域名后，根据 Vercel 给出的目标，在腾讯云 DNS 添加 CNAME 记录：

- 主机记录：`quest`
- 记录类型：`CNAME`
- 记录值：以 Vercel 项目界面实时给出的值为准

DNS 生效并通过 Vercel 校验后，HTTPS 证书会自动配置。
