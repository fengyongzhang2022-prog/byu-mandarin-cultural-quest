# 《黑神话：悟空》GAI沉浸式文化任务：完整版验收清单

## 目标学习者与教学法

| 验收要求 | 已实现的产品证据 |
|---|---|
| 美国大学中高级中文学习者 | 产品与Can-Do文件明确标为 Intermediate High–Advanced High；页面为中文输入/语音互动，支持60/75秒组织性讲述。 |
| 差异化教学 | 学生可选择并随时切换“引导表达／自主协商／批判探究”；三者不是能力标签，分别提供句架、功能提示和证据审视。 |
| 游戏化教学 | 游戏场景、国际文化旅行者身份、倒计时、证据袋、任务进度、角色任务和故事完成卡形成游戏化任务结构。 |

## 3–8分钟完整体验链路

| 阶段 | 学生操作与产出 | GAI角色/产品功能 |
|---|---|---|
| Research Pre | 完成pre-quiz、游戏熟悉度、前测文化解释录音（建议至少1分钟，最长3分钟）及转写 | 保存起点材料与背景变量；教师端可在同机回听。 |
| Enter | 以“国际文化旅行者”身份进入《黑神话：悟空》场景，接受澄清类比的任务 | Story Guide设定故事、任务和角色目标。 |
| Discover | 查看场景物证、文化说明、多元声音/冲突材料；留下理解与疑问 | 形成可带入后续对话的证据袋与整合札记。 |
| Interact | 与“西游行者”直接进行多轮中文对话 | Virtual Character与Language Interaction Partner通过追问、回应和情境推进促进连续输出。 |
| Compare | 与国际玩家Maya解释、举例、协商并调整表达；可打开表达工具 | Intercultural Partner提出真实疑问/误解；工具提供句架、交际功能或证据审视问题。 |
| Explain | 面向Maya录制/输入60秒（批判探究75秒）中文文化解释 | 留下初次文化解释、视频/转写与时间数据。 |
| GAI Story Studio | 查看一条反馈与GAI整理的“中国故事卡”，完成20/25秒修订讲述 | GAI反馈不代写学生答案；故事卡保留学生核心观点，分别标记AI内容与学生产出。 |
| Research Post | 完成post-quiz、理解变化评分、学习日记和访谈线索 | 形成前后比较及质性分析材料。 |

## 研究与演示核对

- 课堂演示链路完整呈现：Immersion → Role-taking → Interaction → Cultural Inquiry → Chinese Language Output → Intercultural Explanation。
- 研究端可导入/导出：pre/post quiz、前后文化解释、Discover札记、双角色AI日志、支持方式切换、GAI反馈/故事卡、修订产出、学习日记、访谈线索及人工编码。
- 技术策略：当前原型以服务端 `/api/chat` 支持两个角色与故事整理；如改用Coze，可将同一调用接口转发至“西游行者”和“国际玩家”两个智能体，学生端和研究数据结构无需改变。
- 场景视频：当前使用游戏场景；可在Enter/Discover替换为教师实录景点视频，任务链路无需修改。
