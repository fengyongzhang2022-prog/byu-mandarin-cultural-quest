# 治沙微短片：专家核对脚本

## 定位与使用方式

- 对象：美国中高级中文学习者（ACTFL Intermediate High–Advanced Low）。
- 位置：网站第七页“时代背景”，两支讲解型历史重建之后接一段2026年真实新闻。
- 形式：类似 Khan Academy 的讲解型微纪录片。由同一位中性旁白沿手绘地图和时间轴讲述，不使用人物第一视角、数字人或“历史人物对镜头说话”。
- 功能：聚焦“5000美元—5万多棵树”的故事，同时把关键行动放回1980—2000年代的毛乌素治沙背景中。
- 显著标识：片头和片尾显示“依据公开资料制作的教学讲解｜画面为示意重建｜非历史影像”。
- 语言负荷：每支约60—75秒；每个段落只承载一个主要信息，关键词和数字随旁白逐步出现。

## 共同视觉语法

两支视频共享一条横向时间轴。时间轴不是装饰，而是帮助学习者持续确认“现在讲到哪一年”。

- 地图：先定位中国北方、毛乌素沙地、洛阳，再按需要画出联系路径。
- 时间：年份由一支手绘笔依次写出，不一次展示全部结局。
- 数字：`600 → 约10`、`14年`、`5000美元`、`5万多棵`在旁白到达时才出现。
- 背景窗口：每当故事进入新年代，用8—12秒交代一项直接相关的社会条件，然后立即回到人物行动。
- 资料边界：历史人物只以姓名、剪影、照片局部或行动图示出现，不生成正面表演或虚构引语。

## 微短片一：毛乌素的十四年

**核心问题**：1999年的电视报道让萨科尔斯基看见了什么？这项行动此前已经发生了多久？

**看后应会**：

1. 按顺序说出1978、1985、1986和1999四个时间点。
2. 听辨“600棵—约10棵—14年”。
3. 说明1980年代的生活条件为什么使治沙首先成为生存问题。
4. 用“到……时，已经……”组织时间关系。

### 旁白定稿

> 毛乌素沙地位于中国北方，跨越内蒙古和陕西。1978年，中国启动“三北”防护林体系建设工程。“三北”指东北、华北和西北，工程通过植树、种草和保护植被来防风固沙。但到了1985年，毛乌素沙地深处有一个叫井背塘的地方，那里仍然没有公路和电。19岁的殷玉珍住进一间半埋在沙里的土房，风沙一夜就能把门堵住。第二年，她和丈夫卖掉家里唯一的一只羊，换回600多棵树苗。树苗要背进沙地，水要用桶担。一场大风过后，活下来的不到10棵。这样的失败不只发生一次：有一年，5000多棵树苗被沙尘暴掀翻，挖了一个冬天的水渠也几乎被毁掉。他们一遍遍重新栽种，逐渐学会先固定流沙，再种灌木和乔木。十四年后，两人已经种出3万多亩林地。那年10月，在700公里外的洛阳，美国教师罗纳德·萨科尔斯基从电视英语新闻中第一次知道了殷玉珍。电视里的几分钟，把毛乌素十四年的治沙带到了一个远方观众面前。

### 分镜

| 节拍 | 画面与屏幕文字 | 教学作用 |
|---|---|---|
| 1 | 中国轮廓由手绘线出现，依次定位“中国北方—毛乌素—井背塘”；时间轴停在1978 | 建立空间坐标，不假定美国学生已有地理背景 |
| 2 | `1978｜三北工程启动`写入时间轴；北方防护林带以简笔线条延伸，角落标明“国家生态建设背景” | 交代长期中国背景，但不暗示它直接造成个人行动 |
| 3 | 时间轴移到1985；无公路、无电、半埋在沙里的土房和风沙堵门依次画出 | 把“治沙”从抽象环保概念落到生活条件 |
| 4 | `1986`出现；一只羊换成600多棵树苗，担水动作之后，数量尺缩减到不到10棵 | 呈现获取树苗、浇水和低成活率三重困难 |
| 5 | `又一次失败`：5000多棵树苗被风掀翻，冬天挖出的水渠被沙覆盖；随后重新栽种 | 说明困难不是一次性的，避免把坚持讲成一句口号 |
| 6 | 沙障、灌木、乔木按先后顺序绘出；时间轴延伸为`14年｜3万多亩` | 呈现“反复失败—调整方法—持续扩大”的行动逻辑 |
| 7 | 旧电视轮廓出现，地图从毛乌素连到700公里外的洛阳；画面停在`电视里的几分钟` | 让远方观众的“看见”成为自然结尾，不重复年份 |

## 微短片二：电视、邮件与5000美元

**核心问题**：一笔跨国捐款怎样进入已经持续多年的治沙？它能解释哪一部分，又不能代表什么？

**看后应会**：

1. 说明电视报道、电子邮件、基金会、5000美元和2000年见面的先后关系。
2. 准确说明一张美元与其余捐款的用途。
3. 说明进入2000年代以后，哪些条件让运输和种树方式发生了变化。
4. 用“此后……”“随着……”继续讲述时间变化。

### 旁白定稿

> 1999年的电视报道播出后，萨科尔斯基开始给多个机构发送电子邮件。大约两个月后，他通过一家基金会筹集到5000美元。殷玉珍留下一张美元作纪念，其余用于购买更好的树苗。2000年春天，萨科尔斯基来到毛乌素。两人第一次见面，也共同种下一棵树。此后，两人失去联系。殷玉珍一家继续种树、补苗和护林。2007年，一条8公里长的公路修到她家门口，树苗和工具可以用车运进沙地。当地的治沙项目也陆续提供苗木和机械。殷玉珍一家根据树苗的成活情况，不断调整树种和栽种方法。用这笔捐款购买的树苗，后来长成了5万多棵树。2026年的新闻重逢，又把这段跨越二十多年的故事带回镜头。

### 分镜

| 节拍 | 画面与屏幕文字 | 教学作用 |
|---|---|---|
| 1 | 时间轴从1999的电视图标继续延伸；电子邮件连向多个机构节点 | 呈现筹款是一个过程，不是突然出现的结果 |
| 2 | `约两个月`与`5000美元`依次写出；一张美元进入纪念框，其余路径指向树苗 | 解释捐款的具体用途 |
| 3 | 时间轴到2000；洛阳与毛乌素的路径连起，两个人物只以姓名和共同栽树动作图示出现 | 保留人的联系，不模拟第一人称记忆 |
| 4 | 时间轴进入2000年代；`2007｜8公里公路`出现，运苗方式由人背变为车辆运输；苗木、机械、补苗与护林动作随后出现 | 用具体变化说明治沙条件如何改善 |
| 5 | 当年购买的树苗沿时间轴逐渐长高，画面出现`后来长成5万多棵树` | 交代这笔捐款产生的具体结果，不插入旁白式免责声明 |
| 6 | 时间轴停在2026，画面转接到真实新闻的播放入口 | 从教学重建自然进入真实语料 |

## 为什么需要时代背景

需要，而且不能只剩一句“长期治理也很重要”。对美国大学生而言，至少需要看见三层条件：

1. **1980年代的生活条件**：井背塘交通、取水和机械条件有限，风沙会堵门，树苗要靠人运进沙地。它解释殷玉珍为什么开始，也解释最初的低成活率。
2. **中国北方的长期生态建设**：1978年启动的“三北”工程提供时代坐标，让学习者知道个人故事发生在一个持续数十年的中国生态治理进程中。
3. **2000年代的系统变化**：道路、苗木、机械、地方项目、经验积累和科学治沙原则逐渐进入。它解释森林为什么不能归因于一个人或一笔捐款。

背景不独立成一段政策宣讲，而是沿时间轴在人物需要它时出现。每个背景窗口都要回答一个问题：这一时代条件如何改变了种树的困难、方法或可能性？

## 从开源科普视频项目吸收的制作原则

- 采用 Chalkboard 的历史时间轴结构：事实核对、脚本、动画和成片验证分开完成。
- 采用 Excalimate／Excalidraw 的手绘图解逻辑：地图、箭头、圈注和关键词按讲述顺序出现，避免“AI生成整张信息海报”的感觉。
- 采用 Manim／Motion Canvas 的关系动画原则：只有时间、路径、数量和因果发生变化时才运动。
- 采用 Remotion 的字幕分段方法：每屏1—2个意群；每个意群保留完整阅读时间，不逐字跳色。
- 先锁定事实和旁白，再生成腾讯云音轨；画面时长由真实音轨决定。

## 与第三幕真实新闻的关系

前两支片子使用同一位第三人称旁白和同一条时间轴，重建公开材料没有保存为连续视频的历史阶段；第三幕直接嵌入2026年重逢新闻，保留新闻体裁、现场声音和真实人物形象。

三幕形成：

**1980年代的生存与试错 → 1999—2000年的跨国支持 → 2000年代的持续治沙 → 2026年的真实重逢**。

## 制作与质检规范

- 1920×1080，30 fps，H.264/AAC；网站端提供MP4，并保留原始第三方新闻链接兜底。
- 两支历史讲解均使用同一位自然、克制的腾讯云中文旁白，保持纪录片连续性；不再用两个“人物音色”暗示第一视角。
- 先生成音频并读取真实时长，再按音频时长安排节拍和字幕。
- 字幕每屏1—2个意群；只强调时间、数字和因果连接词。
- 配乐若使用，只保留极低音量的纸面、风声或室内环境层，不能盖过辅音与数字。
- 输出后检查：黑帧、静音、字幕溢出、音量、首尾资料声明、事实数字和移动端播放。
