# 小西天 · 一座古寺的第二次生命

面向美国大学 Intermediate High–Advanced Low 中文学习者的《黑神话：悟空》GAI 沉浸式文化任务。

学生从游戏画面进入真实山西，使用“古寺—游戏—流量”事实卡，与美国玩家、文保人员或青年志愿者进行连续语音对话，选择三项治理措施，再把小西天与 Yosemite 的游客进入管理作有边界的跨文化比较。核心产出为一段 60–90 秒的证据型中文解释；AI 给出一条建议后，学习者补说 20–30 秒。真实措施揭晓后，四条扩展阅读路径长期开放。

- 学生端：`public/heishenhuawukong.html`
- 教师与研究端：`public/teacher.html`
- 登录页：`public/login.html`
- GAI 角色接口：`app/api/chat/route.js`

角色对话通过服务端调用 DeepSeek。部署时设置机密环境变量 `DEEPSEEK_API_KEY`；未设置或请求失败时，产品使用事实边界内的稳定课堂演示回复。密钥只存在服务端。

任务前录音、对话语音、最终解释和补说媒体保存在学生浏览器的 IndexedDB；结构化过程记录保存在 localStorage。教师端可在同一设备回放原始媒体，也可导入学生导出的 JSON。正式跨设备自动集中收集仍需接入符合研究伦理和数据治理要求的数据库与对象存储。

网站采用学生/教师角色登录。生产环境必须设置高强度随机变量 `AUTH_SESSION_SECRET`；账号密码明文不进入仓库。

教学设计与扩展阅读材料位于 `docs/`。当前比赛版聚焦“数字传播让文化遗产获得第二次生命”，袈裟主题材料保留供后续课程开发使用。
