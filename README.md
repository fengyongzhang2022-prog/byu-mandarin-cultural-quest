# 寻迹 · BYU中文文化任务

面向美国大学中高级中文学习者、对齐 2026 NCSSFL-ACTFL Intermediate High–Advanced High Can-Do 的《黑神话：悟空》生成式AI沉浸式跨文化角色扮演原型。

学生沉浸体验位于 `public/3.html`；研究工作台位于 `public/teacher.html`。学生以“国际文化旅行者”身份进入游戏场景，与“西游行者”和国际玩家Maya进行双向中文互动，使用可切换的差异化支持，完成前后测验、发现札记、文化协商、一分钟文化讲述、GAI故事整理、修订讲述、日记与访谈线索。研究端可汇总并导出全过程数据。

角色对话通过 `/api/chat` 在服务端调用 DeepSeek。部署时设置机密环境变量 `DEEPSEEK_API_KEY`；未设置或请求失败时，产品自动使用稳定的多轮课堂演示回复。密钥只存在服务端，不能提交到仓库。

当前研究数据默认保存在学生浏览器。学生导出JSON后，研究者可在研究工作台批量导入并统一导出；一分钟视频以参与者编号命名并单独提交。正式跨设备自动集中收集需另接符合研究伦理要求的数据库与访问控制。

网站采用学生/教师角色登录。生产环境必须设置高强度随机变量 `AUTH_SESSION_SECRET`；账号密码的明文不进入仓库，代码仅保存课程演示账号的SHA-256校验值。

本项目是非商业教学原型，视觉素材为原创生成，不隶属于或代表《黑神话：悟空》及其权利方。

教学设计、ACTFL 对齐、学习者预期产出与域名部署说明见 `docs/`。
